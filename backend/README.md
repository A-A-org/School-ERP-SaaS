# School ERP SaaS - Backend

A multi-school management system built with Django REST Framework and PostgreSQL.

## Features

- JWT authentication.
- Role-based access control.
- Multi-school data isolation.
- School, user, student, and employee management.
- Class and subject management.
- Fee and attendance management.
- Exam and grade management.
- Student and class academic reports.
- Financial and attendance summary reports.
- Date-range filtering and input validation.

## Technology Stack

- Python 3.9
- Django 4.2
- Django REST Framework
- PostgreSQL
- Simple JWT
- Git and GitHub

## Requirements

- Python 3.9 or compatible version.
- PostgreSQL.
- The dependencies listed in `requirements.txt`.
